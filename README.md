## Performance and Computational Trade-offs of Shallow–Deep Neural Network Fusion for Edge-Oriented Intrusion Detection

Intrusion detection in edge computing requires accurate classification with manageable computational demands. This study evaluates Shallow--Deep Hybrid Fusion Neural Networks for binary network attack detection using the UNSW-NB15 dataset. We investigated six decision-level fusion methods using 20 and 39 numerical features and compared them with standalone shallow and deep neural networks, Random Forest, XGBoost, and architectural ablations. The evaluation comprised 28 model configurations, each tested across five random seeds, producing 140 experimental executions on a balanced dataset of 186,000 records. Concatenation and subtraction provided comparatively stable hybrid performance, achieving mean accuracies of 93.78\% and 93.83\% for the 20-feature and 39-feature configurations, respectively. However, the standalone Deep39 model achieved 94.10\% accuracy, while Random Forest and XGBoost reached 97.36\% and 95.17\%, respectively, using 39 features. Ablation experiments further showed that removing the concatenation classification head reduced model complexity without compromising mean accuracy. These findings demonstrate that shallow--deep fusion does not consistently outperform simpler alternatives. The study highlights the importance of strong baselines, repeated evaluations, and computational trade-offs when selecting intrusion detection models for further edge deployment assessment.
